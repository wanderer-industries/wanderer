# /api/v1 Authorization Hardening Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every `/api/v1` JSON:API resource deny-by-default so a map API token can reach only its own map and resources linked to that map, without affecting internal callers.

**Architecture:** Add `Ash.Policy.Authorizer` + a `policies` block to each route-exposed resource, gated by the domain's `authorize :when_requested`. A shared `WandererApp.Api.Policies.MapScoped` module provides custom checks that (a) allow plain-`User` actors (internal calls) and (b) scope `ActorWithMap` token actors to `actor.map.id` via filter/relationship checks. Deny-by-default catches everything else.

**Tech Stack:** Elixir, Ash 3.9, AshJsonApi 1.4, AshPostgres, ExUnit.

## Global Constraints

- Ash `authorize` mode: `:when_requested` (actor presence triggers enforcement — verified in `lib/ash/actions/helpers.ex`).
- Token actor is `WandererApp.Api.ActorWithMap{user, map}`; internal actor is a plain `WandererApp.Api.User`.
- Token scope is strictly single-map: `actor.map.id`.
- Reads use **filter** checks (out-of-scope rows excluded → list subset, `GET /:id` → 404). Writes use **simple** checks (out-of-scope → 403).
- ACLs are scoped via the `map_access_lists` join (`exists(map_access_lists, map_id == ^map_id)`), not owner identity.
- Extract the token map with `WandererApp.Api.ActorHelpers.get_map/1` (already handles `ActorWithMap` and context shapes).
- No global domain bypass. Every resource opts in explicitly.
- Commit after each task. Run `mix compile --warnings-as-errors` and the relevant tests before each commit.

```elixir
# lib/wanderer_app/api/policies/map_scoped.ex
defmodule WandererApp.Api.Policies.MapScoped do
  @moduledoc """
  Ash policy checks that scope `/api/v1` requests to the map carried by an
  `ActorWithMap` token actor. Plain `User` actors (internal calls) are trusted.
  """

  alias WandererApp.Api.ActorHelpers
  alias WandererApp.Api.ActorWithMap

  def trusted_user, do: {__MODULE__.TrustedUser, []}
  def in_token_map(path) when is_list(path), do: {__MODULE__.InTokenMap, path: path}
  def write_in_token_map(path) when is_list(path),
    do: {__MODULE__.WriteInTokenMap, path: path}

  defmodule TrustedUser do
    use Ash.Policy.SimpleCheck

    @impl true
    def describe(_opts), do: "actor is a trusted internal user"

    @impl true
    def match?(%ActorWithMap{}, _context, _opts), do: false
    def match?(%{id: _}, _context, _opts), do: true
    def match?(_actor, _context, _opts), do: false
  end

  defmodule InTokenMap do
    use Ash.Policy.FilterCheck

    @impl true
    def describe(_opts), do: "row belongs to the token's map"

    @impl true
    def filter(actor, _context, opts) do
      path = Keyword.fetch!(opts, :path)

      case ActorHelpers.get_map(%{actor: actor}) do
        %{id: map_id} -> build_expr(path, map_id)
        _ -> expr(false)
      end
    end

    # [:map_id] -> expr(map_id == ^map_id)
    # [:system, :map_id] -> expr(system.map_id == ^map_id)
    # [:map_access_lists, :map_id] with exists semantics handled by caller path
    defp build_expr([attr], map_id), do: Ash.Expr.expr(^Ash.Expr.ref(attr) == ^map_id)

    defp build_expr(path, map_id) do
      {rel_path, [attr]} = Enum.split(path, -1)
      Ash.Expr.expr(^Ash.Expr.ref(attr, rel_path) == ^map_id)
    end
  end

  defmodule WriteInTokenMap do
    use Ash.Policy.SimpleCheck

    @impl true
    def describe(_opts), do: "changeset target belongs to the token's map"

    @impl true
    def match?(actor, %{changeset: changeset} = _context, opts) when not is_nil(changeset) do
      path = Keyword.fetch!(opts, :path)

      with %{id: map_id} <- ActorHelpers.get_map(%{actor: actor}),
           row_map_id when not is_nil(row_map_id) <- resolve_map_id(changeset, path) do
        row_map_id == map_id
      else
        _ -> false
      end
    end

    def match?(_actor, _context, _opts), do: false

    # For a direct [:map_id] path, read it from the changeset (attribute or data).
    defp resolve_map_id(changeset, [:map_id]) do
      Ash.Changeset.get_attribute(changeset, :map_id) ||
        Map.get(changeset.data || %{}, :map_id)
    end

    # Relationship paths (e.g. via :system) are resolved against loaded data.
    defp resolve_map_id(changeset, path) do
      get_in_struct(changeset.data, path)
    end

    defp get_in_struct(nil, _), do: nil
    defp get_in_struct(struct, [key]), do: Map.get(struct, key)
    defp get_in_struct(struct, [key | rest]), do: get_in_struct(Map.get(struct, key), rest)
  end
end
```

> Implementer note: `Ash.Expr.ref/1,2` + `expr/1` construction is the uncertain part. Keep the same `filter/3` contract and builder names so downstream tasks are unaffected. Verify with the Task 1 tests plus a real query in Task 3.
