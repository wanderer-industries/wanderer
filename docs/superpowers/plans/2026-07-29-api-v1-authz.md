# /api/v1 Authorization Hardening Implementation Plan (revised — round 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make every `/api/v1` JSON:API resource deny-by-default so a map API token can reach only its own map and resources linked to that map, without breaking internal callers — and make `/api/v1` token-only so no session actor can gain cross-tenant access.

**Architecture:** `/api/v1` accepts only map bearer tokens (session branch removed). Each route-exposed resource gets `Ash.Policy.Authorizer` + a `policies` block (`bypass` for trusted internal `User`/`Character`, then action policies), gated by the domain's `authorize :when_requested`. A shared `WandererApp.Api.Policies.MapScoped` supplies the checks. Policies follow each resource's **real** route/action matrix. The one hand-written controller gets a guard + actor propagation; `InjectMapFromActor` is left unchanged (cross-map create is rejected by a policy).

**Tech Stack:** Elixir, Ash 3.9, AshJsonApi 1.4, AshPostgres, ExUnit.

## Global Constraints

- Ash `authorize` mode: `:when_requested`.
- **`/api/v1` is token-only.** The only HTTP actor is `%ActorWithMap{map: %{id: _}}`. Internal in-process actors are plain `%WandererApp.Api.User{}` or `%WandererApp.Api.Character{}` (trusted via bypass). A `%ActorWithMap{map: nil}` is **denied**, never trusted.
- **Composition:** `bypass Trusted` then action policies. Never stacked unconditional `policy` blocks.
- Reads use **filter** checks (out-of-scope → excluded → list subset / `GET :id` 404). Writes → **403** out-of-scope.
- **Real route/action matrix governs policies AND tests** (below). Never POST/PATCH to a route that doesn't exist.
- Cross-map create on `map_system`/`map_connection` → **403 via a create policy** (`create_map_matches_token`), NOT a changeset error (which is `:invalid` → 400/422). `InjectMapFromActor` unchanged.
- `map` create is **token-forbidden** (`:new` mints a new id; `write_direct(:id)` can't apply). Do not group `map` create with update/destroy.
- ACLs (`access_list`, `access_list_member`) and `map_access_list`: **token writes forbidden**; token reads scoped. `user_activity`: token **denied**.
- Token map via `WandererApp.Api.ActorHelpers.get_map/1`.
- Tests: `use WandererAppWeb.ApiCase`, `import WandererAppWeb.Factory`, `create_authenticated_conn(conn, map)`. Missing factories via `Ash.create/2`. DB assertions via `Ash.count/2` / `Ash.get/2` — **never** `Repo.aggregate` on an `Ash.Query`.
- Before each commit: `mix compile --warnings-as-errors` + the task's tests.
- **Full-matrix mandate:** the test snippets in each task are **starting points, not the complete set**. Before marking a task done, expand its tests so **every row of the route/action matrix for that task's resources** has an executable assertion — list, GET-by-id, and each existing write action, for both foreign (deny) and own (positive control) paths. A task with any uncovered matrix cell is incomplete.

```elixir
# lib/wanderer_app/api/policies/map_scoped.ex
defmodule WandererApp.Api.Policies.MapScoped do
  @moduledoc """
  Policy checks scoping `/api/v1` requests to an `ActorWithMap` token's map.
  Trusted internal actors (plain User/Character) are authorized via a bypass and
  never reach the scoped checks. A session ActorWithMap{map: nil} is NOT trusted.
  """
  def trusted, do: {__MODULE__.Trusted, []}
  def in_token_map(path) when is_list(path), do: {__MODULE__.InTokenMap, path: path}
  def write_direct(attr \\ :map_id), do: {__MODULE__.WriteDirect, attr: attr}
  def parent_in_token_map(path) when is_list(path), do: {__MODULE__.ParentInTokenMap, path: path}

  def create_parent_in_token_map(parent_resource, fk),
    do: {__MODULE__.CreateParentInTokenMap, parent_resource: parent_resource, fk: fk}

  defmodule Trusted do
    use Ash.Policy.SimpleCheck
    @impl true
    def describe(_), do: "actor is a trusted internal User or Character"
    @impl true
    def match?(%WandererApp.Api.User{}, _ctx, _opts), do: true
    def match?(%WandererApp.Api.Character{}, _ctx, _opts), do: true
    def match?(_actor, _ctx, _opts), do: false
  end

  defmodule InTokenMap do
    use Ash.Policy.FilterCheck
    alias WandererApp.Api.ActorHelpers
    @impl true
    def describe(_), do: "row belongs to the token's map"
    @impl true
    def filter(actor, _ctx, opts) do
      path = Keyword.fetch!(opts, :path)
      case ActorHelpers.get_map(%{actor: actor}) do
        %{id: map_id} -> ref_eq(path, map_id)
        _ -> expr(false)
      end
    end
    defp ref_eq([attr], v), do: expr(^Ash.Expr.ref(attr) == ^v)
    defp ref_eq(path, v) do
      {rel, [attr]} = Enum.split(path, -1)
      expr(^Ash.Expr.ref(attr, rel) == ^v)
    end
  end

  defmodule ParentInTokenMap do
    use Ash.Policy.FilterCheck
    alias WandererApp.Api.ActorHelpers
    @impl true
    def describe(_), do: "row's parent belongs to the token's map"
    @impl true
    def filter(actor, _ctx, opts) do
      path = Keyword.fetch!(opts, :path)
      case ActorHelpers.get_map(%{actor: actor}) do
        %{id: map_id} ->
          {rel, [attr]} = Enum.split(path, -1)
          expr(^Ash.Expr.ref(attr, rel) == ^map_id)
        _ -> expr(false)
      end
    end
  end

  defmodule WriteDirect do
    use Ash.Policy.SimpleCheck
    alias WandererApp.Api.ActorHelpers
    @impl true
    def describe(_), do: "changeset target belongs to the token's map"
    @impl true
    def match?(actor, %{changeset: %Ash.Changeset{} = cs}, opts) do
      attr = Keyword.get(opts, :attr, :map_id)
      with %{id: map_id} <- ActorHelpers.get_map(%{actor: actor}),
           row when not is_nil(row) <-
             Ash.Changeset.get_attribute(cs, attr) || Map.get(cs.data || %{}, attr) do
        row == map_id
      else
        _ -> false
      end
    end
    def match?(_actor, _ctx, _opts), do: false
  end

  defmodule CreateParentInTokenMap do
    use Ash.Policy.SimpleCheck
    require Ash.Query
    alias WandererApp.Api.ActorHelpers
    @impl true
    def describe(_), do: "created row's parent belongs to the token's map"
    @impl true
    def match?(actor, %{changeset: %Ash.Changeset{} = cs}, opts) do
      parent = Keyword.fetch!(opts, :parent_resource)
      fk = Keyword.fetch!(opts, :fk)
      with %{id: map_id} <- ActorHelpers.get_map(%{actor: actor}),
           parent_id when not is_nil(parent_id) <- Ash.Changeset.get_attribute(cs, fk) do
        case Ash.read_one(
               Ash.Query.filter(parent, id == ^parent_id and map_id == ^map_id),
               authorize?: false) do
          {:ok, nil} -> false
          {:ok, _} -> true
          _ -> false
        end
      else
        _ -> false
      end
    end
    def match?(_actor, _ctx, _opts), do: false
  end

  defmodule CreateMapMatchesToken do
    use Ash.Policy.SimpleCheck
    alias WandererApp.Api.ActorHelpers
    @impl true
    def describe(_), do: "created row's supplied map_id matches the token map (or is absent)"
    @impl true
    def match?(actor, %{changeset: %Ash.Changeset{} = cs}, _opts) do
      case ActorHelpers.get_map(%{actor: actor}) do
        %{id: map_id} ->
          supplied =
            Map.get(cs.params, "map_id") || Map.get(cs.params, :map_id) ||
              Ash.Changeset.get_argument(cs, :map_id) ||
              Ash.Changeset.get_attribute(cs, :map_id)

          is_nil(supplied) or to_string(supplied) == to_string(map_id)

        _ -> false
      end
    end
    def match?(_actor, _ctx, _opts), do: false
  end
end
```
