# Codex behavior

You have permission to freely read, create, edit, and refactor files in this repository.

Do not ask for confirmation before:
- editing existing files
- creating new files
- refactoring code
- renaming symbols or files
- running build, test, lint, or dev commands

Ask for confirmation ONLY if:
- an action is destructive or irreversible
- data loss is possible

Assume all code changes are intentional and approved.
